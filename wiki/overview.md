# MindLeaf

MindLeaf is a digital reading companion that helps users build and sustain a reading habit through gamification, streak tracking, and AI-powered book coaching.

It is built as two applications:
- **mindleaf-api** — Next.js App Router backend with MongoDB/Mongoose
- **mindleaf-app** — Expo React Native mobile app

The project was initiated by Naman Jain (PRD draft v1.0, April 2026).

## Core Features
- 10-book curated reading lineup
- Daily streak tracking and gamification
- AI book coach for discussion and comprehension
- Highlight and note management
- Progress tracking with visual feedback

## Tech Stack
| Layer | Technology |
|-------|-----------|
| API | Next.js App Router |
| Database | MongoDB via Mongoose |
| Mobile | Expo (React Native) |
| State | Zustand |
| Routing | Expo Router v3 |
| Media | Cloudinary |
